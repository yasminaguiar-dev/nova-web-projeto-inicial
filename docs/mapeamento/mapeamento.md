## 2. Mapeamento dos Componentes

### 2.1 Pasta assets

A pasta `assets` reúne os recursos utilizados no projeto.

#### CSS

A pasta `css` é destinada aos arquivos de estilização do projeto, responsáveis pela aparência visual das páginas.

#### Icons

A pasta `icons` contém os ícones utilizados na interface:

* `compras.svg` — ícone relacionado às compras.
* `pesquisar.svg` — ícone de pesquisa.
* `usuario.svg` — ícone relacionado ao usuário.

#### Images

A pasta `images` contém as imagens dos produtos utilizados no projeto:

* `acessorios01.jpg`
* `blusa01.jpg`
* `calça01.jpg`
* `vestido01.jpg`

## 3. Documentação do Projeto

A pasta `docs` reúne os materiais produzidos durante o planejamento e desenvolvimento do projeto.

### Cronograma

Contém o arquivo `cronograma.md`, com o planejamento e a sequência das atividades realizadas no projeto.

### EAP

Contém o arquivo `EAP.md`, com a Estrutura Analítica do Projeto e a divisão das etapas do trabalho.

### Kanban

Contém a imagem `Kanban Nova Web.png`, referente ao quadro Kanban desenvolvido no Trello para organização das tarefas.

### Mapeamento

Contém este documento, responsável por registrar a estrutura de pastas, componentes e navegação do projeto.

### Wireframes

Contém a imagem `Wireframe Projeto.png`, utilizada para representar visualmente a estrutura das páginas antes do desenvolvimento.

## 4. JavaScript

A pasta `js` contém o arquivo:

* `script.js` — arquivo responsável pelas funcionalidades e interações JavaScript do projeto.

## 5. Páginas do Projeto

A pasta `pages` contém as páginas HTML desenvolvidas.

### `index.html`

Página inicial do projeto, responsável pela apresentação inicial do site e pela navegação do usuário.

### `produtos.html`

Página destinada à apresentação dos produtos disponíveis no projeto, utilizando as imagens de acessórios, blusas, calças e vestidos.

## 6. Arquivos de Documentação na Raiz

### `Guia_de_estilo_Inicial.md`

Documento relacionado às definições iniciais do guia de estilo do projeto.

### `NOTAS_ESTUDO.md`

Arquivo utilizado para registrar anotações e informações relacionadas ao desenvolvimento e aos estudos realizados durante o projeto.

### `README.md`

Documento principal de apresentação e documentação do repositório.

## 7. Árvore de Navegação

A navegação atual do projeto está organizada da seguinte forma:

```text
Página Inicial
│
└── Produtos
```

* `index.html` → Página Inicial
* `produtos.html` → Produtos

## 8. Organização dos Requisitos e Componentes

O projeto foi organizado de forma a separar suas principais funções:

* **HTML** → estrutura e conteúdo das páginas.
* **CSS** → estilização e identidade visual.
* **JavaScript** → funcionalidades e interações.
* **Imagens** → imagens utilizadas nos produtos.
* **Ícones** → elementos gráficos da interface.
* **Pages** → páginas HTML do projeto.
* **Docs** → documentação, planejamento e registros do desenvolvimento.
* **README.md** → apresentação e documentação principal do projeto.
